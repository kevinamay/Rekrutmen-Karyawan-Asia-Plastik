# Rekrutmen-Karyawan-Asia-Plastik

Sistem Informasi Rekrutmen Karyawan PT Asia Plastik berbasis Next.js 14, Tailwind CSS, dan TypeScript.

## Fitur Utama
- **Landing Page & Loker**: Informasi lowongan pekerjaan yang tersedia di PT Asia Plastik.
- **Autentikasi**: Registrasi dan login akun pelamar.
- **Status Pelamar**: Tracking timeline dan status tahapan seleksi secara transparan & real-time.
- **Biodata & Profil**: Pengisian biodata lengkap pelamar, pendidikan, dan pengalaman kerja.
- **Screening Dokumen**: Unggah dokumen persyaratan (KTP, CV, Ijazah, Transkrip, Surat Sehat, dll).
- **Tes Kompetensi Online**: Ujian tes tertulis/keahlian teknis secara online dengan timer.
- **Tes Psikologi Online**: Asesmen psikologi calon karyawan dengan format pilihan ganda.
- **AI Interview Simulation**: Sesi wawancara berbasis AI interaktif dengan rekaman respons kandidat.

## Menjalankan Aplikasi Secara Lokal

1. Pastikan dependensi sudah terinstall:
   ```bash
   npm install
   ```

2. Jalankan development server:
   ```bash
   npm run dev
   ```

3. Buka browser di [http://localhost:3000](http://localhost:3000).

## Build Production
```bash
npm run build
npm start
```
