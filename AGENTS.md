# Aturan Pengembangan Project

## Git Auto-Push Rule
- Setiap kali ada penambahan, pengeditan, atau penghapusan file dalam project ini, buat git commit dengan pesan yang jelas dan deskriptif.
- Segera jalankan `git push origin main` setelah commit agar repository GitHub (`https://github.com/kevinamay/Rekrutmen-Karyawan-Asia-Plastik.git`) selalu sinkron dengan kondisi terkini.
